The Kini documentation provides a hosted [Model Context Protocol (MCP)](https://modelcontextprotocol.io/) endpoint. Connect your AI assistant or agent to search and reference our documentation, API endpoints, webhooks, and guides directly.

### Endpoint

```text
https://docs.getkini.com/_mcp
```

No authentication is required for public documentation.

---

## Connect your Client

Add the Kini Docs MCP server to your preferred client:

<Tabs>
  <Tab title="Cursor" icon="sparkles">
    Add the server to `.cursor/mcp.json` in your project root, or through **Cursor Settings → Features → MCP**:

    ```json .cursor/mcp.json
    {
      "mcpServers": {
        "kini-docs": {
          "command": "npx",
          "args": [
            "mcp-remote",
            "https://docs.getkini.com/_mcp",
            "--timeout",
            "120000"
          ]
        }
      }
    }
    ```
  </Tab>

  <Tab title="Claude Code" icon="terminal">
    Add the endpoint using the Claude Code CLI:

    ```bash
    claude mcp add kini-docs --transport http --url https://docs.getkini.com/_mcp
    ```

    Or add it to `.mcp.json` in your project root:

    ```json .mcp.json
    {
      "mcpServers": {
        "kini-docs": {
          "command": "npx",
          "args": [
            "mcp-remote",
            "https://docs.getkini.com/_mcp",
            "--timeout",
            "120000"
          ]
        }
      }
    }
    ```
  </Tab>

  <Tab title="Claude Desktop" icon="bot">
    Add the server to your `claude_desktop_config.json`:

    ```json claude_desktop_config.json
    {
      "mcpServers": {
        "kini-docs": {
          "command": "npx",

            "--timeout",
            "120000"
          ]
        }
      }
    }
    ```
  </Tab>

  <Tab title="Codex & Other Clients" icon="code">

  </Tab>
