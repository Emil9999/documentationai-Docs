## Model Context Protocol (MCP) Setup

Kini provides a hosted [Model Context Protocol (MCP)](https://modelcontextprotocol.io/) reader endpoint. Connect your AI assistant or agent to give it direct, read-only access to our live documentation, API schemas, webhooks, and integration guides.

<Callout kind="info">
**MCP Endpoint:** `https://docs.getkini.com/_mcp`

No authentication or API key is required to access public documentation.
</Callout>

---

## Coding Agents Setup

Add the Kini Docs MCP server to your preferred coding agent or IDE:

<Tabs>
  <Tab title="Cursor" icon="sparkles">
    Add the server to `.cursor/mcp.json` in your project root, or configure it via **Cursor Settings → Features → MCP**:

    ```json .cursor/mcp.json
    {
      "mcpServers": {
        "kini-docs": {
          "command": "npx",
          "args": [
            "mcp-remote",
            "https://docs.getkini.com/_mcp",
            "--timeout",
            "120000"
          ]
        }
      }
    }
    ```
  </Tab>

  <Tab title="Claude Code" icon="terminal">
    Add the endpoint directly using the Claude Code CLI:

    ```bash
    claude mcp add kini-docs --transport http --url https://docs.getkini.com/_mcp
    ```

    Or add it to `.mcp.json` in your project root:

    ```json .mcp.json
    {
      "mcpServers": {
        "kini-docs": {
          "command": "npx",
          "args": [
            "mcp-remote",
            "https://docs.getkini.com/_mcp",
            "--timeout",
            "120000"
          ]
        }
      }
    }
    ```
  </Tab>

  <Tab title="Claude Desktop" icon="bot">
    Add the server to your `claude_desktop_config.json`:

    ```json claude_desktop_config.json
    {
      "mcpServers": {
        "kini-docs": {
          "command": "npx",
          "args": [
            "mcp-remote",
            "https://docs.getkini.com/_mcp",
            "--timeout",
            "120000"
          ]
        }
      }
    }
    ```
  </Tab>

  <Tab title="Codex & Other Clients" icon="code">
    Add the configuration to your MCP-compatible client's settings:

    ```json

        "kini-docs": {
          "command": "npx",

            "mcp-remote",

            "--timeout",
            "120000"
          ]
        }
      }
    }
    ```
  </Tab>
</Tabs>
