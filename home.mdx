## Quick start

<Steps>
  <Step title="Get an API key" icon="key" title-type="p">
    Sign in to the [Kini Partner App](https://app.getkini.com/) and generate a Bearer API key.
  </Step>

  <Step title="Make your first request" icon="play" title-type="p">
    Call the [List Jobs](/api/jobs/index) endpoint with your API key in the `Authorization` header.
  </Step>

  <Step title="Connect AI agents" icon="bot" title-type="p">
    Connect your AI assistant or agent to our [Reader MCP Server](/guides/agent-quickstart) to search documentation and endpoints directly.
  </Step>
</Steps>
