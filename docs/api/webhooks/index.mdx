## Overview

This section documents the exact payload schema of each webhook Kini delivers, generated from the OpenAPI definition. Use it as the source of truth for field names, types, and enum values.

For conceptual details — when each event fires, what the status values mean, and how delivery and authentication work — see the guide pages under **Events**.

The following webhooks are documented here:

- **Application Sync Status Update** — sent when an application finishes synchronizing to the ATS.
- **Job Update** — sent when a job is created, updated, or archived.
- **Job Booking Status Update** — sent when a job booking's status changes.
